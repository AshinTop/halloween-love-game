# Haunted Hearts — ハロウィンの2人協力パズルゲーム

👻 2匹のおばけ、半分ずつのハート、そして1つのランタン。ルナとローズが8つのおばけ屋敷を抜けて帰れるよう、扉を開けたり、灯りを渡したりして助けてあげましょう。1人でキャラクターを切り替えても、同じ端末を囲んで相談しながら遊んでも楽しめます。

**[ブラウザーで遊ぶ](https://halloween-love-game.crazy3d.org/)** · [全12作のハロウィンゲームを見る](https://github.com/AshinTop/halloween-games) · [⭐ GitHub で Star を付ける](https://github.com/AshinTop/halloween-love-game)

## このゲームの楽しみ方

- 1画面で見渡せる8つの部屋。扉、専用の床、ランタンの受け渡しを少しずつ覚えられます。
- 2匹を別々に動かし、それぞれのハートと出口を目指します。
- 何度でも戻せる Undo、やり直し、現在の状態から計算するヒントを用意。
- 部屋ごとの最少手数記録と、同じ問題を開ける共有リンク。
- オリジナル SVG の風景、任意の合成音、タッチ・キーボード操作、動きを抑える設定に対応。

## 基本ルール

まずルナかローズを選び、その子を動かします。ルナは青いハートを集め、青い月の床を通って青いアーチへ。ローズはピンクのハート、バラの床、ピンクのアーチが担当です。ハートが両方そろい、2匹とも自分の出口に立つとクリア。同じマスには重なれません。

月と星のスイッチは、**誰かが乗っている間**、対応する扉を開けます。降りる前に、相手がまだその扉を通る必要がないか確認してください。別のスイッチで役割を引き継げる部屋もあります。

**霧のマスへ入れる**のはランタンを持っている子だけです。2匹が隣り合うと灯りを渡せます。すでに霧の中にいる子は、ランタンを渡したあとでも霧の外へ出られます。この違いが、後半の協力の鍵になります。

制限時間も手数制限もありません。8つの部屋の開始位置からの最短手順は、順に **8、18、22、20、19、24、28、30 手**と検証されています。まずは自分のペースで帰宅し、そのあと少ない手数に挑戦してみてください。

## 操作方法

| 操作 | 入力 |
| --- | --- |
| おばけを選ぶ | 顔アイコンか盤面のおばけを押す。**Q** で切り替え |
| 移動 | 矢印キー / **WASD**、方向ボタン、または隣のマスを押す |
| ランタンを渡す | 隣り合った状態で **L** または受け渡しボタン |
| 1手戻す | **Z** または **Undo** |
| ヒント・やり直し・部屋選択 | ゲーム内の各ボタン |

## ちょっとしたコツ

先に「扉を支える子」の立ち位置を決めると、行き詰まりにくくなります。灯りを渡すための隣のマスも残しておきましょう。ヒントは**今の状態**から最短経路を探し、担当する子を選んで次の行動を教えます。自動では動きません。そこから解けなくなった場合は、数手戻すか最初から試せます。

## 記録とチャレンジの共有

クリアした部屋の最少手数、言語、音の設定は、現在のブラウザーに保存されます。再読み込みすると選択中の部屋を最初から始めるため、未クリアの移動途中までは復元しません。端末間の同期はありません。

たとえば[部屋6のリンク](https://halloween-love-game.crazy3d.org/#room=6)は、その部屋の開始位置を開きます。共有では実際のクリア結果とリンクをコピーし、プレイ動画や手順の記録はアップロードしません。クリップボードが使えない場合は、手動でコピーできる文字を表示します。

## よくある質問

### 2人そろわないと遊べませんか？

1人で両方のおばけを切り替えれば、すべての部屋を解けます。2人なら同じ端末で交代や相談を楽しめます。離れた端末をつなぐ通信プレイはありません。

### 扉が閉じたり、霧へ入れなくなったりするのはなぜ？

扉には対応するスイッチを踏む役が必要です。霧へ入るときにはランタンが必要です。助ける側を動かす前に、両方の条件を確かめましょう。

### 恋愛の相性を診断するゲームですか？

ハートとおばけを題材にした協力型の論理パズルです。名前の入力や相性の採点は行いません。

## ローカルで実行・サイトに埋め込む

リポジトリのルートで HTTP サーバーを起動します。

```sh
python3 -m http.server 4173
```

**http://localhost:4173/** を開いてください。ビルドや依存パッケージは不要です。`file://` では JavaScript モジュールを読み込めない場合があります。

Node で付属のチェックを実行します。

```sh
npm test
```

8部屋すべてのクリア手順、衝突、専用床、スイッチと扉、ランタンの受け渡し、霧への進入、不正な部屋リンクをチェックします。

```html
<iframe src="https://halloween-love-game.crazy3d.org/?embed=1"
  title="Haunted Hearts"
  style="display:block;width:100%;height:521px;border:0"
  allow="fullscreen" allowfullscreen></iframe>
```

主サイトのデスクトップ枠は約 **833×521**。ブラウザーでは **356×280、326×280、390×650、844×340** も確認しています。縦に短い枠では常設の方向ボタンが便利です。スマートフォンで高さを確保できる場合は **480 px 以上**が快適です。iframe は自動で小窓向け配置になり、`?embed=0` で通常ページに戻せます。

寸法、保存、フォーカス、権限は[埋め込みガイド](EMBEDDING.md)へ。親サイトのツールバーを除いた高さを iframe に割り当ててください。
