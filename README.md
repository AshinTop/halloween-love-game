# Haunted Hearts｜双幽灵心动逃脱

Midnight Candy Club 系列，为 love-game.org 制作的原创万圣节合作解谜游戏。当前包含完整的 8 关可玩内容，支持英文与简体中文、单人切换角色或同设备两人轮流操作。

## 游玩

在本目录运行 `python3 -m http.server 4173`，打开 `http://localhost:4173`。无需构建、CDN、账号或后端。

方向键 / WASD 移动，Q 切换幽灵，Z 撤销；也可使用触屏方向按钮或点击相邻格子。两名角色分别收集自己的半颗爱心，到达自己的拱门。月亮和星星机关控制相应的门；专属地砖区分角色；灯笼只能在相邻时传递，携灯者才能进入迷雾。

## 完整功能

- 8 个逐步引入机制的单屏关卡，全部经状态空间求解器验证可解。
- 可无限撤销、重开、基于当前局面的真实下一步提示。
- 经典机关解谜基础上的合作开门、角色专属通道、共享灯笼创新。
- 原创矢量美术、合成音效、音效开关、减少动效设置支持。
- 本地保存每关最佳步数、语言与音效偏好；分享当前关卡链接。

## 验证

`npm test` 使用 Node 内置测试，检查八关完整解路、墙与角色碰撞、专属地砖、机关门、灯笼传递和迷雾规则。求解器最短解为 8 / 18 / 22 / 20 / 19 / 24 / 28 / 30 步。

不含在线多人、账户同步或真实关系评分。两人合作采用同设备轮流操作；分享功能复制文字和题号链接，不上传个人数据。

## 文件

- `engine.js`：纯逻辑、关卡与求解器。
- `app.js`：交互、双语、合成音效、本地存储。
- `style.css`：响应式主题。
- `tests/engine.test.js`：有意义的规则与关卡验解测试。

## 主站嵌入

游戏会自动识别 iframe 并启用紧凑布局；也可用 `?embed=1` 预览。已适配主站桌面窗口和 356 × 280 / 326 × 280 手机小窗，方向按钮、角色切换和必要工具无需页面滚动。具体参数、权限、建议的 480 px 手机游戏窗和浏览器验收记录见 [EMBEDDING.md](EMBEDDING.md)。
